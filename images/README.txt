このフォルダに服の画像を入れてください (jpg / jpeg / png / webp)。

フォルダ名からブランドと時期 (年_シーズン) を自動で読み取ります。
分かる情報だけでフォルダを作れば OK です。分からないものは「未指定」になります。

  images/
  ├── prada/
  │   ├── 2018_SS/001.jpg     ← ブランド + 時期
  │   └── 002.jpg             ← ブランドだけ
  ├── 2019_FW/003.jpg         ← 時期だけ
  └── 004.jpg                 ← 指定なし

時期フォルダの書き方: 2018 / 2018_SS / 2018_FW / 2018-spring など
入れたら、1つ上のフォルダにある run.command をダブルクリックしてください。
