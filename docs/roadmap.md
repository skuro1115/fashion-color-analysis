# 将来の計画（ロードマップ）

最終的には **「集める → 分析する → 伝える」** を 3 つの道具でつなぐ構想です。
いまあるのは ① だけで、② ③ は **まだ作る予定はありません**（構想のメモ）。

```mermaid
flowchart LR
  A["② データ収集ツール<br/>(構想)"] -->|"images/ + manifest.csv"| B["① 分析ツール<br/>(このリポジトリ・稼働中)"]
  B -->|"output/dataset.csv"| C["③ パワポ作成 skill<br/>(構想)"]
```

| | 道具 | 状態 | ひとことで |
| --- | --- | --- | --- |
| ① | 分析ツール | ✅ 稼働中 | 服の画像から代表色を取り出して CSV にする |
| ② | データ収集ツール | 💭 構想のみ | ブランドのページから服の画像と情報を集めて ① に渡す |
| ③ | パワポ作成 skill | 💭 構想のみ | ① の結果からブランド・年代の色の傾向をスライドにする |

やりたいことが決まったら、AI に **「要望を整理したい」**（`/request`）と伝えると、要望書を一緒に作れます。 → [AI で改修する](ai-customization.md)

## ① 分析ツール（このリポジトリ）

**いまできること**：画像 → 商品の切り抜き → 代表色（メイン・サブ）と面積 → `dataset.csv`（1画像1行）＋ 確認ページ

**次にやるかもしれないこと**（優先度は未定）

| 候補 | 目的 |
| --- | --- |
| ブランド × 年代の集計（`brand_year_summary.csv`）とグラフ | 色の変遷を数字と図で見る |
| 色名・色系統への分類（navy, gray, red …） | 「紺が 25%」のように言葉で集計する |
| 実画像 200 枚での精度確認と閾値調整 | review 率・失敗パターンを把握する |
| 確認ページの改善（review だけの一覧、手動で修正した結果の反映） | 人の確認を速くする |
| Windows 対応、画面（Streamlit 等）で操作 | 使える人を増やす |
| 複雑な背景向けの背景除去（重いモデルはオプション扱い） | review を減らす |

## ② データ収集ツール（構想）

**やりたいこと**：ブランドの商用ページから服の画像と情報（ブランド・性別・時期・商品名・URL）を集め、① がそのまま読める形で保存する。
**用途（ジャケットだけ等）での絞り込みは、この収集の段階で行う**前提。① では用途を判定しない。

作るときに決めること

- どのサイトから、どの単位（シーズン・カテゴリ）で集めるか
- サイトの利用規約・robots.txt・著作権の確認（収集してよい範囲）
- アクセス間隔などサイトに負荷をかけない工夫、収集記録（いつ・どこから）の保存
- 半自動（人がページを開いて保存を補助する）か、自動か

## ③ パワポ作成 skill（構想）

**やりたいこと**：① の `dataset.csv` を読み、ブランド・年代・性別ごとの色の傾向をスライドにする（Claude の skill として作る想定）。

作るときに決めること

- 誰に見せる資料か、何枚くらいか、社内テンプレートの有無
- 入れたい図（年代ごとのカラーパレット、色の割合の推移、ブランド比較 など）
- review=True の画像を含めるか

## 道具どうしの約束（インターフェース）

② ③ をあとから作っても ① とつながるように、受け渡しの形をここで決めておく。
**① を変更するときも、この約束を壊さないこと。**

### ② → ①：`images/` と `manifest.csv`

```text
images/[ブランド/][性別/][年_シーズン/]画像.jpg     フォルダは任意・順不同（ないものは未指定）
```

- 画像：jpg / jpeg / png / webp。白背景の商品単体が理想
- `manifest.csv`：`image_id` 列が必須（`images/` からの相対パス・拡張子なし）。
  `brand` `year` `season` `gender` はフォルダより優先。`source_url` `product_name` `category` など追加列は自由（`images.csv` にそのまま付く）

### ① → ③：`output/dataset.csv`

- 1画像1行。`image_id` `brand` `year` `season` `gender`、`main_*` / `sub1_*` / `sub2_*`（`hex` `ratio` `r` `g` `b_rgb` `L` `a` `b`）、`n_colors` `all_colors` `review` `review_reasons`
- 空欄のメタデータ = 未指定（集計で除外しない）
- 列の追加は末尾のみ。既存列の名前・意味は変えない
