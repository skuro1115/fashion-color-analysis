# HSB（色相・彩度・明度）でも評価する

- 状態：完了
- 対象：① 分析ツール
- 作成日：2026-09-24
- 依頼者：Kuroda

## 1. 目的（なぜやりたいか）

ブランド・年代ごとの色の傾向を「鮮やかになった」「明るい色が増えた」のように言葉で説明できるようにする。

## 2. やりたいこと

- dataset.csv のメイン色・サブ色に、色相・彩度・明度（HSB）の値が付く
- 確認ページでもメイン色の HSB が見られる

## 3. 入力と出力

| | 内容 | 例 |
| --- | --- | --- |
| 入力 | 既存の analysis の色（画像の再解析は不要） | |
| 出力 | dataset.csv 末尾に `main_hue` `main_sat` `main_bri`（sub1, sub2 も） | 紺 #1C2542 → 225.8°, 57.6, 25.9 |

## 4. できたと言える条件

- [x] 紺・ベージュ・赤の色相が見た目どおりになる
- [x] 黒・白・グレーは色相が空欄になる
- [x] 既存の列の並びが変わらない

## 5. やらないこと

- 色のクラスタリング・統合を HSB に変える（Lab のまま。HSB は無彩色で色相が不安定で、差と見た目が一致しないため）
- LCh（Lab 由来の明るさ・鮮やかさ・色相）の追加（必要になったら別途）

## 6. 決まっていないこと・確認したいこと

- 無彩色とみなす基準（`dataset.achromatic_chroma: 8`）は実画像を見て調整する

## 7. AI メモ（AI が記入）

- 実現方法：`colorspace.rgb_to_hsb` を追加し、`analysis/dataset.py` で各色に付与。無彩色判定は Lab の chroma
- 設定変更だけでできるか：いいえ（小さなコード追加）
- 道具どうしの約束への影響：dataset.csv の末尾に列追加のみ（後方互換）。docs/roadmap.md 更新済み
- おおよその大きさ：小
