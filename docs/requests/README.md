# 要望書

AI と一緒に整理した「やりたいこと」の置き場所です。
AI に **「要望を整理したい」**（Claude Code なら `/request`）と伝えると、質問に答えるだけでここに要望書ができます。

```text
 やりたいことを話す → AI が質問して整理 → 要望書（このフォルダ） → 合意したら「実装して」
```

- 書き方の型：[TEMPLATE.md](TEMPLATE.md)
- ファイル名：`日付-内容.md`（例 `2026-10-01-brand-year-graph.md`）
- 状態：`下書き` → `合意済み` → `実装中` → `完了`（または `見送り`）
