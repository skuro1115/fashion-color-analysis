# 困ったとき

エラーのときは、黒い画面（ターミナル）に **✖ 赤い文字** で理由が出ます。下の表から探してください。

| 画面の表示 | 見るところ |
| --- | --- |
| （ダブルクリックしても開かない / 警告が出る） | [run.command が開けない](#runcommand-が開けない) |
| images フォルダに画像がありません | [画像がありません](#画像がありません) |
| Python が見つかりません | [Python が見つかりません](#python-が見つかりません) |
| 依存ライブラリのインストールに失敗しました | [インストールに失敗](#依存ライブラリのインストールに失敗しました) |
| config.yaml の書き方に誤りがあります | [設定ファイルの誤り](#configyaml-の書き方に誤りがあります) |
| 予期しないエラーが発生しました | [予期しないエラー](#予期しないエラーが発生しました) |

## run.command が開けない

インターネットから取ってきたファイルなので、Mac が初回だけ止めます。

**macOS 15 (Sequoia) 以降**

```text
run.command をダブルクリック → 警告が出たら「完了」
   ↓
 システム設定 → プライバシーとセキュリティ
   ↓
 下の方の「"run.command" は…」の横にある「このまま開く」
   ↓
 もう一度ダブルクリック → 「このまま開く」
```

**macOS 14 以前**：`run.command` を **右クリック → 開く → 開く**。

2回目からは普通にダブルクリックで開けます。

<details><summary>それでも「アクセス権がない」と出る場合</summary>

ターミナル（アプリケーション → ユーティリティ）を開き、`chmod +x ` と入力（最後に空白）してから
`run.command` をターミナルにドラッグ＆ドロップし、Enter を押してください。
</details>

## 画像がありません

- `images` フォルダの**中**に画像を入れてください（jpg / jpeg / png / webp）
- `images` の中のフォルダに入っていても大丈夫です
- HEIC（iPhone の写真形式）は使えません。プレビュー.app で「書き出す → JPEG」してください

## Python が見つかりません

どちらかを行ってから、もう一度 `run.command` をダブルクリックしてください。

1. **おすすめ**：[python.org](https://www.python.org/downloads/macos/) から「macOS 64-bit universal2 installer」をダウンロードしてインストール
2. 「コマンドライン・デベロッパ・ツールをインストールしますか？」と出た場合は「インストール」を押す

## 依存ライブラリのインストールに失敗しました

- インターネットにつながっているか確認して、もう一度実行
- 大学・会社のネットワークで失敗する場合は、自宅やテザリングで試す
- それでもだめなら、フォルダ内の `.venv-run` フォルダを削除してもう一度実行
  （`.` で始まるフォルダは Finder で `⌘ + Shift + .` を押すと見えます）

## config.yaml の書き方に誤りがあります

`config.yaml` を編集した後に出るエラーです。

- 行頭の空白（インデント）がずれていないか
- `:` の後に半角スペースがあるか
- 分からなければ [GitHub の config.yaml](https://github.com/skuro1115/fashion-color-analysis/blob/main/config.yaml) の内容で上書きする

## 予期しないエラーが発生しました

`output/logs/error_日時.log` に詳細が保存されています。
Claude Code 等の AI にこのファイルを見せて「このエラーを直して」と頼むと調べてもらえます。 → [AI で改修する](ai-customization.md)

## 結果がおかしい

| 症状 | 対処 |
| --- | --- |
| 背景の色が main color になっている | 確認ページで review になっているはず。背景がシンプルな画像に差し替える |
| 同じ色が何色にも分かれて出る / 違う色なのに1色にまとまる | `config.yaml` の `merge_delta_e`（今は 10）を変えます。大きくするとまとまりやすく、小さくすると分かれやすくなります |
| 確認ページで元画像が表示されない | `images` / `output` フォルダの場所や名前を変えずに、`output/preview.html` を開いてください |
