# AI で改修する

コードを読まなくても、Claude Code などの AI に **やりたいことを日本語で伝えるだけ** で機能を変えられます。
このリポジトリには AI 向けの説明書（[AGENTS.md](../AGENTS.md)）が入っているので、AI が構成やルールを自分で把握します。

```text
 Claude Code を起動  →  やりたいことを伝える  →  AI が変更・テスト  →  run.command で確認
```

---

## 始め方

1. [Claude Code](https://claude.com/claude-code) を用意する（デスクトップアプリが簡単です）
2. このフォルダ（`fashion-color-analysis`）を開く
3. 下の例のように頼む

どのファイルを直すべきかを知っている必要はありません。

---

## 頼み方の例

### 設定を変える

```text
代表色を10色ではなく15色取得するように変更して
```

```text
影で同じ色が何色にも分かれるので、似た色をまとめるようにして
```

```text
画像をもっと高画質で解析するようにして
```

### 結果の見せ方を変える

```text
review=true の画像だけ別ページで見られるようにして
```

```text
ブランドごとの年代別グラフを追加して
```

```text
main color を、ブランド・年・シーズンごとに集計した CSV を作って
```

### データを増やす

```text
CSV に product_name 列を追加して
```

```text
manifest.csv に書いたカテゴリ（jacket, shirt など）ごとに色を集計したい
```

### 使い方を変える

```text
UI を Streamlit で作って。画像フォルダを選んで実行できるようにしたい
```

```text
Windows でもダブルクリックで動くようにして
```

### 困ったとき

```text
output/logs/error_20260923_101500.log のエラーを直して
```

```text
この画像（images/prada/2018_SS/003.jpg）の main color が背景の色になってしまう。原因を調べて
```

---

## うまく頼むコツ

| コツ | 例 |
| --- | --- |
| **目的** を書く | 「年代ごとの流行色を比べたいので…」 |
| **具体的な画像や数字** を添える | 「003.jpg で白が 40% と出るが、実際は 10% くらい」 |
| **確認方法** も頼む | 「変更したら samples の画像で動作確認して」 |
| 大きな変更は **先に案を出してもらう** | 「実装する前に、どう変えるか提案して」 |

---

## 変更後の確認

1. `run.command` をダブルクリック
2. 確認ページ（`output/preview.html`）で結果を見る
3. おかしければ、そのまま AI に「〜がおかしい」と伝える

変更を元に戻したいときは「さっきの変更を元に戻して」と頼めます。
