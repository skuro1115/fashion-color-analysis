# AI に頼む（相談・実行・改修）

コードを読まなくても、Claude Code などの AI に **やりたいことを日本語で伝えるだけ** で機能を変えられます。
このリポジトリには AI 向けの説明書（[AGENTS.md](../AGENTS.md)）が入っているので、AI が構成やルールを自分で把握します。

```text
 Claude Code を起動  →  やりたいことを伝える  →  AI が変更・テスト  →  run.command で確認
```

---

## AI の4つのモード

やりたいことに合わせて、AI は4つのモードで動きます。**普通に話しかければ AI が自分でモードを選びます。**
Claude Code なら `/` に続けて名前を打って、直接呼ぶこともできます。

| モード | こんなとき | 話しかけ方の例 | できあがるもの |
| --- | --- | --- | --- |
| 🧭 **使い方を理解する** `/guide` | 使い方・結果の意味が知りたい | 「review が多いのはなぜ？」 | 説明（ファイルは変えない） |
| ▶️ **ツールを実行する** `/run-analysis` | 分析を回したい | 「images の画像を分析して」 | 結果と、その要約 |
| 📝 **要望を整える** `/request` | 新しい機能・変更がほしい | 「年代ごとのグラフがほしい」 | 要望書（[docs/requests/](requests/)） |
| 🔄 **最新版にする** `/update` | ツールの新しい版を取り込みたい | 「更新したい」「最新にして」 | 最新のツール（あなたの画像・設定・結果はそのまま） |

```text
 📝 要望を整える  →  要望書に OK を出す  →  「実装して」  →  ▶️ 実行して確認
```

いきなり「実装して」と頼んでもかまいませんが、大きな変更は先に 📝 で整理すると、思っていたものと違う…を防げます。
これから作る予定の道具（データ収集ツール・パワポ作成）は [将来の計画](roadmap.md) にあります。

## 始め方

1. [Claude Code](https://claude.com/claude-code) を用意する（デスクトップアプリが簡単です）
2. このフォルダ（`fashion-color-analysis`）を開く
3. 下の例のように頼む

> **Claude Code で使うなら、ZIP より「取ってくる」方法がおすすめです。**
> 空のフォルダを Claude Code で開いて「https://github.com/skuro1115/fashion-color-analysis を clone して」と頼むだけです。
> こうしておくと、Claude Code を開いたときに新しい版があれば知らせてくれて、「更新したい」の一言で最新にできます。
> ZIP 版でも使えますが、更新するときは ZIP を取り直すことになります。

どのファイルを直すべきかを知っている必要はありません。

```text

```




```text

```


```text
CSV に product_name 列を追加して
```

```text

```

```text
この画像（images/prada/2018_SS/003.jpg）の main color が背景の色になってしまう。原因を調べて
```

## うまく頼むコツ

| コツ | 例 |
| --- | --- |
| **目的** を書く | 「年代ごとの流行色を比べたいので…」 |
| **具体的な画像や数字** を添える | 「003.jpg で白が 40% と出るが、実際は 10% くらい」 |
| **確認方法** も頼む | 「変更したら samples の画像で動作確認して」 |
| 大きな変更は **先に案を出してもらう** | 「実装する前に、どう変えるか提案して」 |

---

## 変更後の確認

1. `run.command` をダブルクリック
2. 確認ページ（`output/preview.html`）で結果を見る
3. おかしければ、そのまま AI に「〜がおかしい」と伝える

変更を元に戻したいときは「さっきの変更を元に戻して」と頼めます。
